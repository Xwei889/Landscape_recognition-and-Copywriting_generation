毕业设计：基于图文多模态融合的风景场景识别与文案生成系统设计与实现

系统功能说明

>> 核心功能

  • 本地图片上传与实时预览
  • 基于 CLIP 多模态对齐的风景场景智能分类识别
  • 基于本地大语言模型（Qwen2.5-7B）的智能文案生成
  • 多种推荐风格一键选用 + 自定义要求灵活调整
  • 生成文案一键复制，快速分享

>> 技术架构

  • 视觉模块：OpenAI CLIP ViT-B/32 零样本分类
  • 语言模块：Ollama 本地部署 Qwen2.5-7B 大语言模型
  • 后端：Flask + Python
  • 前端：Vue 3 + 新野兽派设计风格
