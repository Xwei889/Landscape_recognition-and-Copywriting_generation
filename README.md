# 风景场景识别与文案生成系统

## 项目简介
这是一个基于 Flask 框架、Vue3 前端和 CLIP 多模态大模型构建的风景图像识别与智能文案生成系统。系统能够自动识别用户上传的风景图片场景，并根据治愈、文艺、伤感三种风格自动生成适配的风景文案，界面采用顶部导航 + 左右分栏布局，所有功能一屏展示无需滚动，整体简洁美观、运行稳定。
## 核心功能
- **图像上传预览**：支持本地风景图片上传与实时预览，兼容主流图片格式
- **多模态场景识别**：基于 CLIP 模型自动识别八大类风景场景
- **多风格文案生成**：一键生成治愈、文艺、伤感三种风格文案
- **左右分栏展示**：左侧操作区 + 右侧结果区，一屏完整展示无需滚动
- **页面模块切换**：首页、作者介绍、系统说明三大页面
- **本地离线运行**：模型本地加载，无需联网即可使用全部功能

## 环境要求
- Python 3.10+
- Flask
- PyTorch
- CLIP
- Pillow
- NumPy

## 快速开始
1. 安装依赖
```bash
pip install flask torch clip pillow numpy
```

2. 模型部署（必须）
下载 CLIP 模型文件 `ViT-B-32.pt`，放入项目 `model/` 文件夹

3. 启动项目
```bash
python app.py
```

4. 访问地址
```
http://127.0.0.1:5000
```

## 使用说明
1. 启动项目后进入系统首页
2. 上传风景图片并选择文案风格
3. 点击生成按钮，右侧展示识别结果与文案
4. 可通过顶部导航查看作者介绍与系统说明
5. 模型部署完成后支持完全离线使用
