- 基于图文多模态融合的风景场景识别与文案生成系统
- 
- 📖 项目简介
- 本项目为人工智能专业毕业设计，基于多模态大模型 CLIP 实现风景图片场景识别与智能文案生成。系统采用前后端分离架构，后端基于 Flask 搭建轻量服务，前端使用 Vue3 实现交互界面，能够对用户上传的风景图像进行场景分类，并根据治愈、文艺、伤感三种风格自动生成适配的风景文案，实现“图像理解 + 智能文案创作”的完整多模态应用。
- ✨ 核心功能
- 风景图像上传与预览：支持本地图片上传、实时预览，兼容常见图片格式
- 多模态场景识别：基于 CLIP 模型实现风景场景智能识别，涵盖山林、海边、落日、古镇、湖泊、街巷、草原、城市天际线等常见风景类别
- 多风格文案生成：内置治愈、文艺、伤感三种文案风格，一键切换生成对应文案
- 左右分栏可视化展示：左侧上传操作、右侧结果展示，一屏完整展示，无需滚动
- 响应式交互界面：顶部导航栏设计，包含首页、作者介绍、系统说明三大模块
- 本地离线运行：模型本地加载、无需联网，运行稳定、响应速度快
-

- 📦 模型文件配置（必看）
- 本项目依赖 OpenAI CLIP 预训练多模态模型，项目初始源码未附带模型权重文件（模型文件体积较大），需手动下载并放置到指定目录，否则项目无法正常完成场景识别与文案生成功能。
- 1. 模型下载信息
- 选用模型：CLIP ViT-B/32 通用风景识别模型
- 下载来源：Hugging Face 官方开源仓库
- 模型文件：ViT-B-32.pt 权重文件
- 备用下载：国内镜像加速下载（适配国内网络，下载速度更快）
- 2. 模型部署步骤
- 1. 下载完成后，获取完整的 ViT-B-32.pt 模型权重文件；
- 2. 在项目根目录下找到 model 文件夹（无则手动新建）；
- 3. 将下载好的模型文件直接放入 model/ 目录下；
- 4. 重启 Flask 服务，系统即可自动加载模型，正常使用识别生成功能。
- 3. 注意事项
- 模型文件名不可修改，必须为ViT-B-32.pt，否则程序读取模型会报错；
- 模型加载首次运行较慢，属于正常现象，等待几秒即可完成初始化；
- 放置模型后即可实现完全离线运行，无需联网即可完成图像识别与文案生成。
- 🚀 运行教程
- 1. 环境配置
推荐使用 Conda 虚拟环境运行，避免环境冲突
conda create -n clip python=3.13
conda activate clip
pip install -r requirements.txt
2. 启动项目
进入项目根目录，运行启动文件：
python app.py
启动成功后，访问地址：http://127.0.0.1:5000
3. 使用流程
1. 进入系统首页，点击上传风景图片
2. 选择需要的文案风格（治愈/文艺/伤感）
3. 点击生成按钮，左侧展示上传图片，右侧实时展示识别场景与生成文案
4. 可切换作者介绍、系统说明页面查看项目信息
